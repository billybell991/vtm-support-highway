Chrome Extension for Jira ↔ Zendesk Ticket Cloning — v1.0 Install Guide

Prerequisites

  • ✓ Google Chrome (or Edge Chromium) browser
  • ✓ Active session logged into Jira at http://atlassian.versaterm.com:8080
  • ✓ Active session logged into Zendesk at https://versatermhelp.zendesk.com
  • ✓ The extension folder (this ZIP, extracted)
How auth works: The extension uses your existing browser sessions (cookies) for both Jira and Zendesk. No passwords are stored. Just be logged in to both systems in the same Chrome profile.

Installation (2 minutes)

1 Extract the ZIP

Extract vtm_support_highway_v1.0.zip to a permanent folder on your computer.

Windows: Right-click → "Extract All" → choose a location like C:\Tools\vtm_support_highway

Mac: Double-click the ZIP → move the folder to ~/Tools/vtm_support_highway

Don't delete this folder! Chrome loads the extension directly from this folder. If you move or delete it, the extension will break.
2 Open Chrome Extensions

Type this in your Chrome address bar and press Enter:

chrome://extensions
3 Enable Developer Mode

Find the "Developer mode" toggle in the top-right corner of the page. Turn it ON.

4 Load the Extension

Click "Load unpacked" (top-left area).

Browse to the folder you extracted in Step 1 (the one containing manifest.json).

Click "Select Folder" (Windows) or "Open" (Mac).

5 Pin the Extension

Click the puzzle piece icon (🧩) in Chrome's toolbar → find "VTM Support Highway" → click the pin icon to keep it visible.

Done! You should see the VTM Support Highway icon in your toolbar. The "Clone to Zendesk" and "Clone to Jira" buttons will also appear automatically on Jira SUP tickets and Zendesk ticket pages.

Quick Start

Option A: From the toolbar icon

  1. Navigate to a Jira SUP ticket or a Zendesk ticket in Chrome
  2. Click the VTM Support Highway icon in the toolbar
  3. The popup auto-detects the ticket and shows a preview with editable fields
  4. Check/uncheck options (copy comments, copy attachments, cross-link)
  5. Click "Create Jira Ticket" or "Create Zendesk Ticket"

Option B: From the in-page button

  1. On any Jira SUP ticket, you'll see a blue "⇄ Clone to Zendesk" button in the toolbar
  2. On any Zendesk ticket, you'll see a blue "⇄ Clone to Jira" button
  3. Click the button → the full preview window opens → review and create

What It Does

FeatureDescription
Create cloneCreates a ticket in the target system with mapped fields, priority, and description
Copy commentsAll comments copied with original author names and timestamps
Copy attachmentsAll files and screenshots transferred to the new ticket
Cross-linkInternal notes added to both tickets linking to each other
Duplicate detectionIf a clone already exists, offers Resync instead of creating a duplicate
ResyncIncrementally syncs new comments and attachments (never duplicates)
CRMS fieldsClient, Contact, Severity, Product, Reference Number mapped for CRMS project

Troubleshooting

ProblemFix
"Jira not configured" errorMake sure you're logged into Jira in the same Chrome profile
"Zendesk not configured" errorMake sure you're logged into Zendesk in the same Chrome profile
Button doesn't appear on Jira pageOnly works on SUP tickets. Refresh the page. Check the extension is enabled.
Button doesn't appear on ZendeskZendesk's SPA can be slow — wait 3-5 seconds. Try refreshing.
Attachment copy failsCheck you're logged into both systems. Some very large files may time out.
Extension disappearedYou may have deleted the source folder. Re-extract and re-load.
"This extension is not from the Chrome Web Store"Normal for developer-loaded extensions. Click "Keep" if prompted.

Updating

  1. Extract the new ZIP, replacing the old folder contents
  2. Go to chrome://extensions
  3. Click the refresh icon (↻) on the VTM Support Highway card
