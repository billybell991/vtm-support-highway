What It Does

VTM Support Highway is a Chrome/Edge browser extension that eliminates the manual copy-paste work of creating tickets across Zendesk and Jira. When a support case in one system needs a matching ticket in the other, the extension transfers everything — summary, description, comments, attachments — in a few clicks, and cross-links the two tickets so agents always know both sides exist.

Prerequisites

  • ✓ Google Chrome or Microsoft Edge browser
  • ✓ Active session logged into Zendesk at https://versatermhelp.zendesk.com
  • ✓ Your Versaterm email address (for the one-time Settings entry)
  • ✓ The extension folder (this ZIP, extracted)
No API token setup needed. The shared API token is built into the extension. Just enter your email in Settings after installation — that's the only step.

Installation (2 minutes)

1 Extract the ZIP

Extract vtm_support_highway_v1.0.zip to a permanent folder on your computer.

Windows: Right-click → "Extract All" → choose a location like C:\Tools\vtm_support_highway

Mac: Double-click the ZIP → move the folder to ~/Tools/vtm_support_highway

Don't delete this folder! Your browser loads the extension directly from this folder. If you move or delete it, the extension will break.
2 Open the Extensions Page

Type one of these in your browser's address bar and press Enter:

BrowserAddress
Chromechrome://extensions
Edgeedge://extensions
3 Enable Developer Mode

Chrome: Find the "Developer mode" toggle in the top-right corner. Turn it ON.

Edge: Find the "Developer mode" toggle in the bottom-left sidebar. Turn it ON.

Edge may also prompt you to "Allow extensions from other stores" — click Allow if asked.

4 Load the Extension

Click "Load unpacked" (top area of the page).

Browse to the folder you extracted in Step 1 (the one containing manifest.json).

Click "Select Folder" (Windows) or "Open" (Mac).

5 Enter Your Email Address

Click the ⚙️ gear icon in the VTM Support Highway popup, then enter your email in both fields:

FieldValue
Jira Cloud > EmailYour Versaterm email (e.g. your.name@versaterm.com)
Zendesk > EmailYour Versaterm email (e.g. your.name@versaterm.com)

The API tokens are already built in — no token setup required. Click Save.

6 Pin the Extension

Chrome: Click the puzzle piece icon (🧩) in the toolbar → find "VTM Support Highway" → click the pin icon.

Edge: Click the puzzle piece icon (🧩) in the toolbar → find "VTM Support Highway" → click the eye icon to show in toolbar.

Done! You should see the VTM Support Highway icon in your toolbar. The "⇄ Clone to Zendesk" and "⇄ Clone to Jira" buttons will appear automatically on Jira CRMS tickets and Zendesk ticket pages.

Quick Start

There are two ways to use the extension — both open the same create ticket screen shown above.

Option A — Click the in-page button (easiest)

  1. Open a Jira CRMS ticket — click the blue ⇄ Clone to Zendesk button (in the header or floating top-right)
  2. — or — open a Zendesk ticket — click the blue ⇄ Clone to Jira button in the ticket header
  3. The create ticket window opens with all fields pre-filled from the source ticket
  4. Review the fields, adjust anything needed, and click Create Jira Ticket or Create Zendesk Ticket

Option B — Use the toolbar popup

  1. Navigate to a Jira CRMS ticket or a Zendesk ticket
  2. Click the VTM Support Highway icon (⇄) in the browser toolbar
  3. The popup auto-detects the current ticket and shows the same preview form
  4. Check/uncheck Copy comments, Copy attachments, and Cross-link as needed
  5. Click Create Jira Ticket or Create Zendesk Ticket
Tip — manual entry: If no ticket is detected automatically (e.g. you opened the popup from a different page), use the manual entry form at the top: choose the source system, enter the ticket key or number, and click Fetch.

Settings

Click the ⚙️ gear icon in the popup header. The only things you need to enter are your email addresses:

FieldValue
Jira Cloud > EmailYour Versaterm email (e.g. your.name@versaterm.com)
Jira Cloud > API Token✅ Pre-configured — do not change
Zendesk > EmailYour Versaterm email (e.g. your.name@versaterm.com)
Zendesk > API Token✅ Pre-configured — do not change

Click Save. You only do this once per machine.

Troubleshooting

ProblemFix
"Jira not configured" errorOpen Settings (⚙), make sure your email is entered, click Save
401 Unauthorized from JiraThe shared API token may have expired. Contact Bill Bell to get an updated extension package.
"Option value is not valid" errorThe Client or Contact field value from Zendesk didn’t match any Jira option. Clear those fields manually in the form before creating
"Zendesk not configured" errorMake sure you're logged into Zendesk in the same Chrome profile
Button doesn't appear on Jira pageJira Cloud loads slowly — wait a few seconds. The floating button (top-right) always appears as a fallback. Refresh if needed.
Button doesn't appear on ZendeskZendesk's SPA can be slow — wait 3–5 seconds. Try refreshing.
Attachment copy failsCheck you're logged into both systems. Some very large files may time out.
Extension disappearedYou may have deleted the source folder. Re-extract and re-load.
"This extension is not from the Chrome Web Store"Normal for developer-loaded extensions. Click "Keep" if prompted.
Edge: "Allow extensions from other stores"Click "Allow" — this is required for non-Edge-store extensions.

Updating

  1. Extract the new ZIP, replacing the old folder contents
  2. Go to chrome://extensions (Chrome) or edge://extensions (Edge)
  3. Click the refresh icon (↻) on the VTM Support Highway card
