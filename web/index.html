VTM SUPPORT HIGHWAY

v1.4.4

A Chrome extension that creates and links tickets across Zendesk, Jira Cloud, and On-Prem Jira (SUP) — one click from a support ticket to a defect or technical request, fully populated and cross-linked.

Quick start

Three steps. Five minutes. No installer.

Step 1 — Download the extension zip

vtm-support-highway-v1.4.5.zip v1.4.4
unpacked Chrome extension · works on Windows + Mac + Linux
Download zip
  1. Unzip it somewhere easy to find (for example: Downloads/vtm-support-highway or Desktop/vtm-support-highway).
  2. In Chrome: open chrome://extensions, toggle Developer mode ON, click Load unpacked, and select the unzipped extension folder.
  3. Configure it: click the toolbar icon, hit the gear, and paste in your Jira Cloud email + API token (and on-prem Jira credentials if you'll be cloning to SUP). Save.
  4. You're done. Open any Zendesk ticket on versatermhelp.zendesk.com and you'll see two new buttons: Clone to Support Defect and Clone to Tech Request.
Updating later: re-download the zip, unzip over the same folder (overwrite all), then go to chrome://extensions and click the ↻ reload arrow on the VTM Support Highway card. Confirm the version number bumps.

Use it

Three entry points cover the whole workflow.

From a Zendesk ticket → clone outward

  1. Open a Zendesk ticket (e.g. versatermhelp.zendesk.com/agent/tickets/148213).
  2. Two amber buttons appear in the ticket header: Clone to Support Defect (Jira Cloud CRMS) and Clone to Tech Request (On-Prem Jira SUP).
  3. Click one. A popup window opens with summary, description, priority, components, and reporter pre-filled from the Zendesk ticket. Tweak anything you need.
  4. Click Create. The extension creates the Jira issue, then writes a private comment on the Zendesk ticket with a link back. Both sides are now cross-linked.

From a Jira issue → check or jump to the Zendesk source

  1. Open any Jira Cloud issue under versaterminc.atlassian.net/browse/….
  2. If the issue was cloned from Zendesk, a banner appears with a one-click link back to the originating ticket.

From anywhere → the toolbar popup

  1. Click the VTM Support Highway icon in the Chrome toolbar.
  2. Paste a Zendesk ticket ID, Jira key, or Aha record — the popup gives you cross-system search, link, and clone actions without needing to be on any particular page.
Auto-online (Zendesk): the extension also flips your Zendesk agent status back to Online after Chrome wakes from idle, so you don't miss tickets routed by status.

What it does

One extension, three systems, zero copy-paste.

Clone Zendesk → Jira Cloud

One click on a Zendesk ticket creates a Support Defect in Jira Cloud CRMS with subject, description, customer, priority and components pre-filled. A private comment with the Jira link is added back to Zendesk.

Clone Zendesk → On-Prem Jira

Same one-click flow targeting the on-prem Jira SUP project for technical requests — honours different field mappings, priorities and components for the on-prem schema.

Cross-link both directions

Every clone writes a back-link comment on the Zendesk side, and the Jira issue carries the originating ticket URL. Banners on Jira pages surface the link without having to dig.

Aha! integration

Look up Aha records and link them into the chain from the toolbar popup — useful when a support ticket maps to an existing roadmap item.

Auto-online for Zendesk

Restores your agent status to Online automatically when Chrome resumes from idle. No more silently missing routed tickets.

Works in the Zendesk SPA

Buttons inject on every ticket as you navigate — no need to refresh the page when you switch tickets in the agent UI.

Troubleshooting

I navigated to a ticket and don't see the buttons

As of v1.4.1 the buttons should always appear on first navigation. If they don't, give it 2–3 seconds for the Zendesk SPA to finish painting the header. Still nothing? Reload the tab once — and if that fixes it, ping Bill with the ticket URL so we can tune the selectors.

"Clone" button does nothing / authentication failure

Open the extension popup, click the gear, and confirm your Jira Cloud email + API token are present and not expired. For on-prem Jira (SUP) the username/password pair lives in the same panel. Save, then try again.

Banner on Jira side missing

The Jira-side banner only appears for issues created by the extension (it reads the linked Zendesk URL from the description). Older issues won't have it.

Updating to a new version

Re-download the zip, unzip over the same folder (overwrite all), then click ↻ on the extension card at chrome://extensions.
